# Dark Notifications

Fabric notifications client for Minecraft **26.2** (this repo targets 26.2).

Prebuilt jars in `releases/` for **1.21.11**, **26.1.2**, and **26.2**.

- Default ClickGUI bind: **Right Shift**
- Default command prefix: **`.`**
- Discord: Darked2b

ClickGUI layout inspired by Midnight client.
