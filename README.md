# Dark Notifications

Fabric client mod for Minecraft with a ClickGUI and notification modules.

## Layout

```
src/client/java/dark/noti/client/
  features/
    commands/
    gui/
    modules/
      client/
      notifications/
    settings/
  manager/
  config/
  mixin/
  util/
```

## Build

Use JDK 21 and Gradle (`./gradlew build` or `./gradlew runClient`).
